# Skills

A skill is a repeatable how-to for agents: one markdown file describing when to use it, the steps, and how to verify the result.

## Lifecycle

Exactly three states, declared in a `Status:` line in the file header:

```text
draft → active → deprecated
```

- A skill may be promoted to `active` only after it has been used successfully **at least once**, with evidence linked in the file.
- Any high/mid-level role may create a `draft` skill in its domain.
- Duplicate skills must be merged, not accumulated.

## No skills yet — by design

The first real skills will be extracted from Phase 3 practice, not invented up front (Constitution P6).
