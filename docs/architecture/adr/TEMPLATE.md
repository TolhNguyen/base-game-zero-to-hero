# ADR Template

> ADRs are immutable once committed. To change a decision, write a new ADR that
> supersedes the old one and update the old ADR's Status line only.
> Numbering: 4 digits, sequential (0001, 0002, ...).

```markdown
# ADR-NNNN: <Title>

- Date: YYYY-MM-DD
- Status: Accepted | Superseded by ADR-NNNN
- Approved by: <dev name> (required for Core-level changes)

## Context
<What forced a decision — 2-5 sentences.>

## Decision
<What we chose — 1-3 sentences, imperative.>

## Alternatives considered
<Bullet list, one line each, with the reason rejected.>

## Consequences
<What becomes easier, what becomes harder, what must be revisited when.>
```
