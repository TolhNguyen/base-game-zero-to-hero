# Domain Docs

One file per game system (`save-system.md`, `inventory.md`, ...), created when the system is first built (Phase 2+).

Rules:

- Required header lines: `Owner role: <Director|Architect>` and `Last verified: YYYY-MM-DD`.
- Maximum one page each.
- Contains what code cannot say — intent, invariants, gotchas. Never restates code.
