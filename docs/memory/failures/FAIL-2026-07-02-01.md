# FAIL-2026-07-02-01: Parse error in demo script passed tools/check

- Status: Closed
- Detected by: human-driven headless run (not by tools/check)

## Symptom

`demo/demo_state.gd` had two `:=` inferences from Variant values (parse errors, warnings-as-errors). `tools/check` reported PASS (83/83) because the import step and the test runner never parse scripts that no test suite loads. The game failed to boot its autoload.

## Root cause

`tools/check` verified tests, not the runnable game. Scripts outside test-suite reach (demo glue, autoloads) were never compiled.

## How it was detected (and why not earlier)

Manual headless `--quit-after` run during T7 acceptance printed the parse errors. Not earlier because no check step ran the actual game.

## System action

Added a boot-smoke step to `tools/check.sh`: run the game headless for a few frames and fail on `SCRIPT ERROR` / `Parse Error` / failed-autoload output. Recorded in ADR-0005; commit contains both. Closed.
