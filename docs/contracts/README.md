# Task Contracts

Executed task contracts live here, named `TASK-YYYY-MM-DD-NNN.yaml` (template: `docs/governance/task-contract-template.md`).

Rules:

- The contract is committed **together with the work it authorized**; the commit body references it.
- Contracts are execution records: immutable once committed (fix mistakes with a follow-up task, not edits).
- Executors refuse contracts with empty fields.
